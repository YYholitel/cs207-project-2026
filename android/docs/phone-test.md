# 手机安装和实板测试

解压 ZIP，安装 EGO1-Puzzle-0.2-debug.apk。Android 8.0 及以上可用。系统要求时，允许当前文件管理器安装应用。旧版签名不匹配时，卸载旧版后安装。

## 先试手机

点「模拟板」→「练习关」。5、7、8 应高亮。点 1 后棋盘原样，无效步数加一。点「撤回」恢复计数。再点 1 和 8，棋盘变为 123456780，统计为有效 1、无效 1。

点「复位」，按 1 2 3 4 5 6 7 0 8 逐格初始化。重复输入显示 E，输入正确编号即可继续。点「开始演示」并推进四次到第五幕，再推进一次重播。

## USB 直连 EGO1

1. 在电脑上给 EGO1 烧录本仓库华容道固件，开启板卡电源。
2. 手机用 OTG 数据线或转接头连接开发板的板载 USB 接口。
3. 点「USB 连接」，选择 EGO1 并允许访问 USB。App 自动选择 FT2232 的 B 串口通道。
4. 出现「已连接 · 棋盘由开发板确认」后，手机显示板上原有棋局。
5. 点「练习关」，点 1 再点 8，核对手机、数码管和 LED。
6. 在开发板操作撤回、复位或展示切换，确认手机随后同步。「板上显示」控制提示/统计，「计数页」控制高低四位。
7. 拔掉数据线，约两秒内提示中断并禁用棋盘。插回后重新点「USB 连接」。

## 蓝牙连接

模块需提供经典蓝牙 SPP 服务，UART 为 115200、8N1、无流控。BLE 模块需要专用 GATT 协议。模块和 FPGA 使用 3.3 V 电平、共地，TX/RX 交叉连接。UART 路径按板卡手册确认，避免蓝牙模块与板载 USB UART 同时驱动 FPGA RX。

先在系统蓝牙设置里配对模块，再点「蓝牙连接」，允许权限并选择模块。连接后重复 USB 的棋盘、板端操作和断线验收。

## 恢复

连接失败后保留最后确认的画面并标记断开，点击连接按钮重试。App 切入后台后释放连接，回前台后需要重连。板卡物理复位会关闭串口写控制，下一次手机主动操作重新开启，后台状态查询仅同步棋盘。

本包包含软件测试记录。OTG 兼容性、模块供电、接线和真实 EGO1 演示，需要在你使用的手机和开发板上执行以上测试。
