# 板卡操作说明

## 输入

板卡正面朝上、数码管位于上方。拨码开关的数据位按**物理从左到右**排列，不能按官方示例 XDC 的数组下标猜测高低位。

| 控件 | 管脚 | 功能 |
|---|---|---|
| S6 / RESET | P15 | 低有效全局复位，任意阶段都可用 |
| S0 | R11 | 确认输入；通关后切换棋盘 / 十进制统计 |
| S1 | R17 | 八灯提示 / 统计切换；复位后第一次按为提示 |
| S2 | R15 | 单步撤回，包括非法移动；可从通关返回上一步 |
| S3 | V1 | 演示下一幕 |
| S4 | U4 | 游戏 / 演示模式切换，清空当前棋局 |
| 前四个相邻拨码，左到右 | P5 P4 P3 P2 | 输入编号的 bit3 bit2 bit1 bit0 |
| 第五个拨码 | R2 | 0：LED 统计低四位；1：高四位 |

按键高有效，10 ms 消抖，长按仅触发一次。拨码经两级同步和 1 ms 稳定过滤；拨好后再按确认，不要一边拨一边确认。

编号输入举例（1=开关高电平）：

| 编号 | 左到右四位 |
|---|---|
| 0 | 0000 |
| 1 | 0001 |
| 2 | 0010 |
| 3 | 0011 |
| 4 | 0100 |
| 5 | 0101 |
| 6 | 0110 |
| 7 | 0111 |
| 8 | 1000 |

## 输出

数码管从左到右依次为棋格 1–8。0 和尚未输入的格子都不亮；错误输入当前位置显示 E，改正输入后继续，之前的合法布局保留。棋格 9 使用 K1、H6、H5、J5 四灯，从左到右依次为 bit3..bit0，8 对应 `1000`，0 为全灭，非法的第九次输入为全亮。

| 指示灯位置 | 功能 |
|---|---|
| 左下八灯 F6 G4 G3 J4 H4 J3 J2 K2 | 提示时分别对应棋子 1–8，亮表示能和空格交换 |
| 同组左四灯 F6 G4 G3 J4 | 统计时为有效步数，左侧为高位 |
| 同组右四灯 H4 J3 J2 K2 | 统计时为无效步数，左侧为高位 |
| K6 | 高级外设 / UART 控制启用 |
| L1 | 手工游戏模式 |
| M1 | 演示模式 |
| K3 | 非法输入时 2 Hz 闪烁，通关后常亮，其余灭 |

计数完整范围为 00–99，99 后饱和。默认 LED 页显示低四位，若计数超过 15，用第五个拨码切到高四位。完整二进制值 = 高页 × 16 + 低页。例如 18：高页 `0001`、低页 `0010`。两项计数同时切页；先切到统计视图才能看到计数。

通关后再按 S0，左侧两位数码管显示有效步数的完整十进制，右侧两位显示无效步数，中间四位灭。例如有效 17 / 无效 18 显示 `17    18`，再按 S0 返回棋盘。第九格仍表示 0。S1 继续可切换 LED 视图。

## 手工游戏范例

1. 按 S6。数码管全暗、统计归零，L1 表示游戏模式。
2. 依次用四位拨码 + S0 输入 `1 2 3 4 5 6 7 0 8`。
3. 按 S1，提示第 5、7、8 个灯亮。
4. 输入 1，按 S0。棋盘不变，错误灯闪；再按 S1 查看无效步数为 1。
5. 输入 8，按 S0。棋盘显示 `12345678`，第九格四灯灭，K3 长亮；有效 1 / 无效 1。
6. 再按 S0，显示 `01    01`。
7. 按 S2，撤回刚才赢棋的移动：棋盘回到 `123456708`，有效 0 / 无效 1；下一次 S2 不再继续倒退。

初始化时可故意输入 F 或重复的数字测试 E；最后一格故意重复可测试四灯全亮。初始化失败不消耗位置，也不计入游戏移动统计。

## 演示模式

手工状态按 S4 进入演示，按 S3 依次推进：

| 幕 | 棋盘 / 显示 | 有效 / 无效 | 状态 |
|---|---|---|---|
| 1 | `123456708` | 0 / 0 | 提示 5、7、8 |
| 2 | 棋盘不变，模拟移动 1 | 0 / 1 | 错误灯闪 |
| 3 | `123456780`，模拟移动 8 | 1 / 1 | 提示 6、8；通关灯常亮 |
| 4 | `01    01` | 1 / 1 | 通关统计 |
| 5 | 全部输出灭 | 0 / 0 | 复位场景；S3 可重播 |

演示中 S0 / S2 不改变预设过程，S1 仍可切换提示/统计。S4 可随时退出演示到全新手工棋局；S6 始终全局复位。

## 串口

在工程目录运行 `python tools/board_cli.py --interactive`，输入 `a` 开启高级控制，K6 点亮。显示的 3×3 棋盘来自 FPGA 的实际寄存器快照。`z` 关闭高级控制后，串口写操作不再改变棋局；只读 `?` 始终可用。实体开关和按键不依赖串口。

若遇到串口冲突，关闭其他串口工具；如设备编号改变，使用 `--port /dev/serial/by-id/...-if01-port0` 指定 B 通道。验收工具结束时会将串口控制关闭并保留演示第一幕。
