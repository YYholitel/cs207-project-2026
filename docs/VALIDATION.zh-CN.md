实板验收读取 FPGA 的原子寄存器和展示逻辑快照，覆盖实际 UART 接口、100 MHz 核心和状态转换。它不等同于用摄像机检查灯珠、数码管亮度、物理接触或真实按钮的机械手感；按钮路径、段码与消隐时序由 RTL 顶层测试覆盖，实际灯光仍可按用户指南直观看板确认。

## 可复现流程

```bash
make sim
make build
make program
make verify
```

`make sim` 每次使用独立仿真目录，避免 Vivado 增量数据库在中断后卡住。测试会检查明确 PASS 标志以及错误输出，而不是只信进程退出码（XSim 某些错误也可能返回 0）。

构建不改变板卡；`make program` 只配置易失 SRAM；`make verify` 会改变游戏状态，结束后固定停在演示第一幕，提示视图开启，UART 控制关闭。

## 覆盖与边界

- 九个初始化位置都测试越界 / 重复输入，包括最后一格错误时 E / 四灯全亮。
- 九种空格位置，每个都测试 0–15 全部编号，包括行边界误连、无效不改盘与精确提示位图。
- 已解决棋盘初始化、一步通关、通关后显示、赢棋撤回、无效操作撤回、二次撤回不继续倒退。
- 计数跨过 15、16、98、99，99 饱和；高低四位页和两位十进制来自完整计数。
- 任意排列（含不可解排列）和随机操作；不是对所有 9! 棋盘穷举，也不宣称形式化证明。
- 演示五幕、多轮重播、演示中不接受手工移动；模式切换 / 全局复位清理。
- 按键抖动不触发、长按单次、物理复位关闭 UART 控制；UART 禁用、错误起始位和停止位不产生写操作。
- 两组数码管高有效、每次数据变化前消隐；输出选择仅允许一列/组。

唯一综合 Warning 是局部组合校验临时变量被优化掉，不影响逻辑；Methodology 的四项 XDCB-5 仅提示同步器引脚查询写法的执行效率，不是电路时序或 DRC 错误。异步 I/O 的输入/输出延迟检查列为已显式设置 false path，与设计没有外部同步时钟的事实相符，内部逻辑没有整体设例外。
