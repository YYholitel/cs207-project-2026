# 演示、实拍与答辩提纲

课程尚未发布最终视频规范。本分镜用于准备；正式视频需要拍到真实开发板，不能拿软件模拟棋盘充当实板证明。

| 时长建议 | 操作 | 应拍到的现象 |
|---|---|---|
| 0:00–0:15 | 展示板卡与控件，按 S6 | 复位、数码管暗、游戏模式灯 |
| 0:15–0:55 | 逐格输入，穿插 F 和重复数字 | 当前格 E、状态闪烁、合法输入保留；第九格非法时四灯全亮 |
| 0:55–1:15 | 完成 `123456708`，S1 提示 | 数码管前八格与第九格二进制；5、7、8 提示灯 |
| 1:15–1:40 | 输入 1 无效，再按 S2 撤回；再输入 1 | 不改盘，无效统计 +1；撤回同步恢复 |
| 1:40–2:00 | 输入 8 赢棋；S0 统计 | 目标盘、状态常亮；`01    01`，与 LED 对应 |
| 2:00–2:15 | S2 撤回赢棋 | 回到原盘、有效归零、无效仍 1 |
| 2:15–2:50 | S4 + 连续 S3 演示 | 初始化→非法→合法通关→统计→全暗复位；重播 |
| 2:50–3:15 | 可选 UART CLI | 真实 FPGA 二维快照、advanced 灯，z 禁用后实体独立可用 |
| 3:15–3:40 | 可选 17 / 18 统计 | 两页完整二进制与十进制一致，解释四灯容量 |

实拍前检查：数码管和 LED 在镜头中清楚，左右方向正确，曝光不致 LED 过亮；用手部操作证明实体输入；如录像帧率导致扫描条纹，调整快门或帧率。说明分工和贡献时填写真实成员、学号和职责，仓库不会虚构团队信息。

答辩应能解释：

1. 组合逻辑与时序逻辑的边界，为什么只有一个真实时钟。
2. 两级同步与消抖分别解决什么问题，为什么长按只有一次确认。
3. 棋格打包顺序与物理左右顺序，0、F、E 的不同含义。
4. 何为上下左右相邻，以及如何防止行尾跨行误判。
5. 撤回为何要同时保存棋盘、两项计数、错误状态及通关状态。
6. FPGA 上实际执行与上位机读取状态的区别。
7. 饱和计数与分页的规则，四位二进制和两位十进制的容量差异。
8. 为何位选切换需要消隐，以及板卡数码管为何高有效。
9. 时序报告 WNS / WHS 的意义，为什么不能靠放宽约束掩盖超时路径。
